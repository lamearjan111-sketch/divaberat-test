# DIVA Territorial Intelligence Prototype

## Overview

This repository contains a prototype developed as part of the DIVA (Digital Innovation for the Valorization of Local Cultural and Environmental Heritage) initiative.

The project explores the integration of structured databases, analytics workflows, and AI-assisted information processing to support territorial intelligence, governance analytics, tourism intelligence, and decision-support systems.

## Main Features

- FastAPI web application
- SQLite database integration
- SQLAlchemy ORM
- Structured data management
- API development and testing
- Prototype architecture for analytics and territorial intelligence applications

## Technologies

- Python
- FastAPI
- SQLite
- SQLAlchemy
- HTML/CSS
- Jinja2 Templates

## Project Context

DIVA is a territorial intelligence framework designed to support data-driven analysis, cultural heritage management, governance analytics, tourism planning, and decision-support processes through integrated data systems and analytical workflows.
